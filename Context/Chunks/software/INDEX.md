# Software Chunks

This category covers the current web application and the configuration needed
to run, lint, and build it. It is the active workstream for the software half of
the two-person project.

- `software/frontend-shell` - App Router root layout, home route, and global styling -> `frontend-shell.md`
- `software/tooling` - package scripts, framework configuration, TypeScript, ESLint, and Tailwind/PostCSS -> `tooling.md`

There is no backend, API, map, routing, persistence, or shared component system
to index yet. Add a focused chunk when one becomes a real source area.
